A simple Python application that calculates the number of days between today’s date and a user-entered date. 
Originally built as a command-line script using NumPy, later extended with TKINTER for GUI for a more user-friendly experience.

Features:
Get today’s date automatically using NumPy.
Enter any date in YYYY-MM-DD format.
Calculate the difference in days between today and the entered date.
Simple Tkinter-based GUI for easier interaction.
