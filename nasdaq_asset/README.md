this project analyzes historical NASDAQ asset data using Python, Pandas, and Matplotlib. 
It includes data cleaning, transformation, and visualization of closing prices, percentage changes, and moving averages.

Features
Load and clean raw CSV data (removes $ symbols, converts to floats).
Convert date column to proper datetime format.
Plot closing price over time.
Calculate and plot percentage change in closing price.
Add and visualize 20-day and 50-day moving averages.
