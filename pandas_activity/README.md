This project explores the 2016 US Primary Elections dataset using Python, Pandas, and Matplotlib.
It provides insights into voting patterns by state and candidate, and allows interactive exploration of vote fractions for specific candidates.

Features
Load and inspect election data from CSV.
Calculate and visualise:
Average votes by state.
Total votes by candidate.
Fraction of votes for a chosen candidate across states.
Interactive input: users can type a candidate’s name to see their vote share by state.
